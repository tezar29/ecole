# Site vitrine — Mon École

Site statique en français présentant les fonctionnalités de l’application Flutter Mon École. Il est déployé par Render depuis la racine du dépôt avec `mkdir -p dist && cp -R site-web/. dist/` et `dist` comme répertoire publié.

Pages : accueil, fonctionnalités, mobile, ordinateur et téléchargements. Les maquettes mobile et ordinateur sont illustratives. Les APK, liens iOS et installateurs Windows ne sont pas fournis dans le dépôt; la page distingue explicitement le ZIP du code source des fichiers installables.

Les visuels sous `assets/` sont les fichiers originaux du dépôt. Les styles et scripts sont autonomes et les liens internes utilisent la racine du site.
